# Stock Market Prediction with News Headlines Impact

A data analytics and machine learning project exploring the relationship between Indian financial news headlines and NIFTY 50 stock-market movements.

## Project overview

The project combines historical stock-market data with company-related news headlines, studies how headline activity relates to market behaviour, and explores whether historical stock and news features can help predict the next day's market return.

This is an exploratory academic project. The models are **not** a reliable investment or trading system.

## What the notebook does

1. **Collect stock data** – downloads historical data for a list of NIFTY 50 companies using `yfinance`.
2. **Match news to companies** – processes the Times of India headlines CSV in chunks and uses a ticker-to-keyword mapping to associate headlines with companies.
3. **Prepare the analysis dataset** – cleans dates and ticker symbols, joins stock records with headline information, and calculates measures such as daily return, price range, and trading volume.
4. **Explore the data** – examines distributions, monthly trends, stock-level performance, and correlations.
5. **Study headline activity** – compares high-news and low-news days and calculates statistical relationships between headline counts and market measures.
6. **Visualize market movements** – creates Matplotlib, Seaborn, and interactive Plotly visualizations, including detected peaks and valleys.
7. **Explore next-day return prediction** – engineers stock and news activity features and evaluates Linear Regression, Random Forest, Gradient Boosting, and XGBoost using a chronological 75/25 train-test split.

## Results recorded in the notebook

The notebook reports 3,242 daily samples and 48 model features. On its held-out test period, the recorded results were:

| Model | Test R² | MAE | RMSE |
|---|---:|---:|---:|
| Linear Regression | -0.0064 | 1.0824 | 1.6836 |
| Random Forest | -0.0339 | 1.0985 | 1.7065 |
| Gradient Boosting | -0.0953 | 1.1616 | 1.7564 |
| XGBoost | -0.1467 | 1.2141 | 1.7971 |

The best test R² was -0.0064 (Linear Regression). These negative R² values mean the tested models did not outperform a simple mean-target baseline on this test set. The results are included transparently rather than presented as a successful forecasting system.

The notebook's market-visualization section reports data coverage from 2010 through 2023.

## Data requirements

The notebook expects the following files at the relevant stages:

- `nifty50_all_stocks.csv` – generated by the stock-data collection cell.
- `india-news-headlines.csv` – the historical Indian news headlines dataset (Times of India / Kaggle source used in the notebook).
- Intermediate files such as `merged_nifty50_company_headlines.csv` and `cleaned_nifty50_data.csv` are generated during processing.

The news CSV is not included in this repository. Obtain it from the dataset provider and place it in the notebook's working directory. Check the dataset's current licence and terms before redistributing it. The notebook's matching and processing cells expect the specified filenames and column structure.

   ```bash
   git clone https://github.com/<your-username>/<your-repository-name>.git
   cd <your-repository-name>
   ```
2. Create and activate a virtual environment:


5. Open Jupyter:
   ```bash
   jupyter notebook
   ```
6. Run the notebook cells in order. The first data-collection cell downloads stock data and saves the CSV needed by later cells.

## Important limitations

- Company matching is based on keywords and regular expressions; ambiguous names can cause false matches.
- Headline volume is used as a proxy for news activity. The notebook does not perform semantic sentiment analysis of headline meaning.
- The analysis dataset removes rows without matched headlines in its cleaning workflow, which can introduce selection bias.
- The model's negative test R² scores show that predictive performance is weak on the reported test period.
- A chronological holdout is used, but further time-series validation and leakage checks would be valuable before drawing stronger conclusions.
- The uploaded notebook references an external `aap.py` Streamlit app, but that application source was not included. This repository therefore contains the analysis notebook, not a verified runnable Streamlit dashboard.
